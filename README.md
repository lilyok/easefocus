# EaseFocus

EaseFocus is a modern Pomodoro planner for turning personal goals into practical, timed tasks.

The app will use Apple’s Foundation Models framework to create personalized plans on supported devices, while keeping manual planning and the Pomodoro timer available to everyone.

## Status

Early planning and design.

## Platform

- SwiftUI
- iOS 26+
- Foundation Models
- SwiftData

## Privacy

Plan generation runs on device. Optional web search will send only the search query needed to retrieve resources; generated plans and survey answers remain local unless clearly disclosed otherwise.
